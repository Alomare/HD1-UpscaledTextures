# Changelog

New, changed, fixed or removed features, one line each, brief and direct. The section for a release becomes the release notes.

## 1.2.0

- Changed: Japanese, Chinese, Korean and Russian text shows correctly again. Each of these languages uses a separate font texture, and the mod no longer replaces that texture with the English one.
- New: About 250 more textures are upscaled. These are the other versions the game stores under the name of a texture that was already upscaled. In 1.1.0 the main version replaced them, so they showed the wrong image.

## 1.1.0

- Changed: Every texture is upscaled again with 4x-PBRify_UpscalerV4, a model trained on game textures. It removes compression damage and smears surfaces far less than the previous model.
- Changed: Colour and brightness stay closer to the original art.
- Changed: Better texture compression, which keeps more of the upscaled detail.
- New: A thumbnail for Obsidian.

## 1.0.0

- New: Upscaled Textures, formerly Enhanced Textures, as a separate download: 1188 game textures at twice the size, upscaled by an AI model.
- New: Obsidian offers updates from this repository.
- Changed: The new name comes with a new mod id, so Obsidian treats this as a different mod. Remove Enhanced Textures before importing this one.
